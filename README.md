# PythonProject7

Проект реализует функционал фильтрации операций по статусу и сортировки по дате. Код написан с использованием строгой типизации (type hints) и соответствует стандартам качества (flake8, mypy).

## Описание проекта

Проект предоставляет следующие возможности:
* Фильтрация операций по статусу
* Сортировка операций по дате
* Генерация тестовых данных
* Маскирование номеров карт и счетов
* Расширенное логирование с помощью декоратора

## Новый функционал: декоратор логирования

### Описание декоратора `log`

Декоратор предоставляет возможность логирования выполнения функций с возможностью вывода в консоль или файл.

### Основные возможности

* Логирование начала и окончания выполнения функции
* Запись результата выполнения
* Обработка и запись ошибок
* Гибкая настройка места логирования

### Примеры использования

```python
# Логирование в консоль
@log()
def simple_function():
    return "Hello, World!"

# Логирование в файл
@log(filename="app.log")
def another_function():
    return "Logging to file"
