# Банковские транзакции

Программа для работы с банковскими транзакциями из JSON, CSV и XLSX файлов.

## 📋 Описание проекта

Программа позволяет:
- Загружать транзакции из файлов различных форматов (JSON, CSV, XLSX)
- Фильтровать операции по статусу (EXECUTED, CANCELED, PENDING)
- Сортировать операции по дате
- Фильтровать рублевые транзакции
- Искать операции по описанию с использованием регулярных выражений
- Подсчитывать количество операций по категориям

## 🚀 Функциональность

### Основные возможности

1. **Загрузка данных**
   - Из JSON-файлов
   - Из CSV-файлов
   - Из XLSX-файлов

2. **Фильтрация**
   - По статусу операции (EXECUTED, CANCELED, PENDING)
   - По рублевым транзакциям
   - По описанию с использованием регулярных выражений

3. **Сортировка**
   - По дате (по возрастанию/убыванию)

4. **Статистика**
   - Подсчет транзакций по категориям

### Новая функциональность (ДЗ 13.2)

#### 1. Поиск транзакций по описанию
- **Функция**: `process_bank_search` в модуле `search.py`
- **Библиотека**: `re` (регулярные выражения)
- **Описание**: выполняет регистронезависимый поиск подстроки в поле `description` транзакций
- **Параметры**: список транзакций и строка для поиска
- **Возвращает**: список транзакций, в описании которых есть искомая строка

#### 2. Подсчет транзакций по категориям
- **Функция**: `process_bank_operations` в модуле `categories.py`
- **Библиотека**: `Counter` из `collections`
- **Описание**: подсчитывает количество транзакций по заданным категориям
- **Параметры**: список транзакций и список категорий
- **Возвращает**: словарь с количеством транзакций по каждой категории

#### 3. Пользовательский интерфейс
- **Функция**: `main` в модуле `main.py`
- **Интерактивный режим** с выбором:
  1. Источника данных (JSON/CSV/XLSX)
  2. Статуса транзакций
  3. Сортировки по дате
  4. Фильтрации рублевых транзакций
  5. Поиска по описанию
