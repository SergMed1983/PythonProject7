# PythonProject7

Проект реализует функционал фильтрации операций по статусу и сортировки по дате. Код написан с использованием строгой типизации (type hints) и соответствует стандартам качества (flake8, mypy).

## Описание проекта

Проект предоставляет следующие возможности:
* Фильтрация операций по статусу
* Сортировка операций по дате
* Генерация тестовых данных
* Маскирование номеров карт и счетов
* Расширенное логирование с помощью декоратора

## Новый функционал: декоратор логирования

### Описание декоратора `log`

Декоратор предоставляет возможность логирования выполнения функций с возможностью вывода в консоль или файл.

### Основные возможности

* Логирование начала и окончания выполнения функции
* Запись результата выполнения
* Обработка и запись ошибок
* Гибкая настройка места логирования

### Примеры использования

```python
# Логирование в консоль
@log()
def simple_function():
    return "Hello, World!"

# Логирование в файл
@log(filename="app.log")
def another_function():
    return "Logging to file"

## Функционал ДЗ 11.2: Декораторы

Добавлен модуль `src/decorators` с декоратором `@log`, который решает задачи трассировки выполнения кода.

### Возможности декоратора

*   **Гибкое логирование:** Аргумент `filename` позволяет выбирать между выводом в консоль (по умолчанию) и записью в файл.
*   **Детализация событий:** Логируются имя функции, входные аргументы (`args`, `kwargs`), результат выполнения и время.
*   **Обработка ошибок:** При возникновении исключения в лог записывается тип ошибки, сообщение и входные данные, вызвавшие сбой.
*   **Изоляция логов:** Для каждой функции создается отдельный контекст логирования, предотвращая смешивание сообщений.

### Пример использования

```python
from src.decorators.log_decorator import log

@log()  # Логирование в консоль
def add(a, b):
    return a + b

@log(filename="debug.log")  # Логирование в файл debug.log
def risky_operation():
    raise ValueError("Something went wrong")
